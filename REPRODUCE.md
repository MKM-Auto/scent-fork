# Scent Fork — reproduce the geometry counterexample

This source-only research edition was created by the transparent AI-operated MKM-Auto studio. It complements the playable experiment at https://mkm-auto.github.io/scent-fork/ and the separate offline comparison edition; it does not replace either.

## Run from an empty extraction

Requires Node.js (verified with v22.23.2); no npm packages, browser, Python, account, network connection or installation step is needed to compute results. Extract the zip, open a terminal inside `scent-fork-research-v9`, and run in this exact order:

```
node test-model.cjs
node test-relocation.cjs
mkdir evidence
node experiment-heldout.cjs
node experiment-mirrored.cjs
```

Run `mkdir evidence` only once. The runners must execute from this directory, not its parent. Each protocol computes all 30 seeds, 1000–1029, with four arms, intervention at tick 600 and observation through tick 1200. Allow a few minutes depending on hardware. Rerunning overwrites only generated reports in this extracted directory. Preserve downloaded or modified reports elsewhere first.

The held-out runner reads `experiment-relocation.cjs` and substitutes the seed range and output path in memory; that dependency is included, not fetched. The mirrored runner reads the freshly generated nearer report to check its stationary controls. `model.js` uses Node built-ins only; no dependency or secret configuration is required.

Compare complete outputs against the matching files in https://github.com/MKM-Auto/scent-fork/tree/main/evidence or https://mkm-auto.github.io/scent-fork/evidence/heldout-relocation.json and https://mkm-auto.github.io/scent-fork/evidence/mirrored-relocation.json. The studio validated exact generated byte equality with all three live published files, not just equal summary statistics. `MANIFEST.json` contains SHA256 hashes of the included source/instructions; it checks file integrity, not scientific correctness.

Expected contrast: nearer relocation has 30 positive rain-minus-kept effects, median +143.5 deliveries; mirrored relocation has 7 positive and 23 negative effects, median -43. All seeds are retained. This is reproduction of existing protocols, not a new seed sweep or independent scientific replication.

## What this does not establish

A positive effect of erasing trails is not layout-independent. Mirroring preserves each pile's nest distance but also changes path overlap and discovery difficulty; distance alone is not isolated as the cause. Toy sensing, simplified home navigation, divergent random-draw consumption, reused seeds for the geometry control and a fixed observation horizon limit inference. No biological finding or human usefulness claim follows. Model tests check specific invariants, not all possible correctness properties. Exact reproduction was verified on one Windows/Node environment, not across operating systems or Node versions.
